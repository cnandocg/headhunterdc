# Headhunter D.C.

Site oficial da banda de Death Metal Headhunter D.C. (Salvador, Bahia, desde 1987).
Português é a página principal; inglês fica em `/en/`.

No ar: https://headhunterdc.pages.dev

## Arquivos

| Caminho | O que é |
|---|---|
| `index.html` | Página principal em português |
| `rise-of-the-damned.html` | Press release em português |
| `en/` | As mesmas duas páginas em inglês |
| `dados/shows.js` | Agenda de shows, usada pelos dois idiomas |
| `css/site.css` | Visual |
| `js/site.js` | Menu, vídeos, Spotify, agenda e formulário |
| `js/brasas.js` | Brasas sobre a arte de fundo |
| `img/` | Imagens |

Site estático: não precisa instalar nem compilar nada. Para ver, abra `index.html` no navegador.

## Como editar

- **Novo show:** edite `dados/shows.js`. As instruções estão no arquivo e datas passadas somem sozinhas.
- **Textos:** altere a página em português e a correspondente em `en/`.
- **Capas e fotos:** troque o arquivo em `img/` mantendo o mesmo nome.
- **Endereço do site:** se mudar de `headhunterdc.pages.dev`, troque também no topo das quatro páginas, em `robots.txt` e em `sitemap.xml`.
